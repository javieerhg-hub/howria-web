# Scripts SQL de Howria Web

Todos los scripts que se han corrido en el SQL Editor de Supabase (proyecto
Howria), numerados en el orden real en que corrieron (o debieron correr —
ver nota al final). El esquema base original (`schema_howria.sql`) no está
acá: se corrió al principio del proyecto, antes de este sistema de
numeración; si hace falta reconstruir la base desde cero, avisar.

**No hay ninguna herramienta automática corriendo esto.** Cada archivo se
sigue pegando a mano en el SQL Editor de Supabase la primera vez que se
necesita — la numeración es solo para saber el orden y no perder el hilo,
no un runner de migraciones.

## Convención para el próximo script

1. Nombre: `NNN_descripcion_corta.sql`, con `NNN` = el número más alto que
   exista hoy en la carpeta, + 1, con ceros a la izquierda (3 dígitos).
2. Encabezado: empezar con un comentario `-- Corre esto en el SQL Editor de
   Supabase (proyecto Howria)` y, si no es obvio, un párrafo de contexto
   (qué problema resuelve, por qué se decidió así) — el estilo que ya
   tienen todos los scripts de abajo.
3. Correrlo en Supabase, confirmar que funcionó, y recién ahí agregarlo a
   este índice y hacer commit.

## Nota sobre el orden 001–023

Estos 23 primeros scripts se agregaron al repo juntos, en un solo commit,
como registro histórico de lo que ya se había corrido a mano en Supabase
desde el principio del proyecto — no hay forma de recuperar la fecha/hora
exacta de cada uno. Se numeraron en el orden en que aparecían (que era
alfabético), **corrigiendo dos casos donde ese orden violaba una
dependencia real y comprobable en el SQL**:
- `018_seguridad_rls_y_auth.sql` agrega `usuarios.email`, columna que
  `019_rls_permisos_por_rol.sql` necesita para poder crear `mi_rol()`/
  `mi_nombre()` — con el orden alfabético original quedaba al revés.
- `013_usuario_javier_arunias.sql` → `020_usuario_javier_arniaz.sql`
  (le corrige el nombre a los clientes de Arunías) → `021_javier_arniaz_admin.sql`
  (lo asciende a administrador) — con el orden alfabético original,
  el script que asciende a Javier Arniaz aparecía antes de que su
  usuario existiera.

Del resto no hay certeza de que el número refleje el orden real en que se
corrieron, pero no se encontró ninguna otra dependencia entre ellos que lo
exija.
